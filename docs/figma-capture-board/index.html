2. Zero-Egress Media CDN & Proxy

  • Object Storage: Cloudflare R2 ($0.015/GB-mo, $0.00 egress) + SHA-256 dedup. At 50 TB/mo egress: ~$250/mo vs ~$4,300/mo on S3 (94% savings).
  • Canvas LOD: Cloudflare Image Transformations transitioning to self-hosted imgproxy (libvips) for 360px/720px WebP tiles + lossless PNG/EXR inputs.
  • Video Pipeline: R2 HTTP 206 faststart MP4s + containerized FFmpeg 8.0 NVENC fleet on Modal L4/H100 workers.
