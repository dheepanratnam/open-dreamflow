# Open-DreamFlow Consumer Subscription Bridge (Manifest V3)

Zero-API-cost Chrome Extension bridging **Open-DreamFlow Studio** (`http://localhost:8789`) directly to your signed-in consumer web subscriptions on:

- **Google Flow** (`https://flow.google.com/*`) — Veo / Gemini Omni `@Element` Ingredient injection + prompt queueing + live `<video>` stream capture.
- **Dreamina / Seedance** (`https://dreamina.capcut.com/*`) — 2–10 Multi-Frame keyframe upload + 9-grid contact sheet & Seedance `<video>` capture.

## Installation (Developer Mode)

1. Open `chrome://extensions` in Google Chrome, Arc, Brave, or Edge.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select `extensions/chrome-bridge/`.
4. Sign in to `https://flow.google.com` and/or `https://dreamina.capcut.com` in normal tabs, then toggle **Consumer Bridge ($0 API)** inside Open-DreamFlow Studio!
